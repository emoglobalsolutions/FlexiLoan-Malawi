
# FlexiLoan Malawi Website

A responsive website prototype built with HTML, CSS and JavaScript.

## Files

- `index.html` — main website page
- `style.css` — website styling and mobile responsiveness
- `app.js` — navigation, demo forms, modals and repayment calculator
- `README.md` — project documentation

## Publish with GitHub Pages

1. Open the repository Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select the `main` branch.
5. Select the `/ (root)` folder.
6. Save and wait for deployment.

Your website URL will follow this format:

https://YOUR-USERNAME.github.io/flexiloan-malawi/

Replace YOUR-USERNAME with your GitHub username.

## Important

This project is a front-end demonstration. Login, registration and loan application forms do not create real accounts or submit real applications.

The repayment calculator uses illustrative values, not an approved lending offer.

Before using this for a real financial business, implement a secure backend, database, verified business details, appropriate legal and regulatory compliance, and authorized payment integrations.

Never collect mobile money PINs or real passwords through this demo.
